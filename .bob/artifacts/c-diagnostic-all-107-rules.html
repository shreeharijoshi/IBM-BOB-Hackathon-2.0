MISSING_SEMICOLON5 rules
#1expected ';' at end of declaration
CompilerThe compiler reached the end of a declaration without finding the required semicolon terminator.FixAdd a semicolon (';') at the end of the declaration.
#2expected ';' after (return|expression|declaration|statement)
CompilerThe compiler expected a semicolon after this construct.FixAdd a semicolon (';') after the statement.
#3expected ';' before '}'
CompilerThe compiler found a closing brace before the expected semicolon.FixAdd a semicolon (';') after the last statement before '}'.
#4expected ';'
CompilerThe compiler reached a token it did not expect because a semicolon is missing.FixAdd a semicolon (';') at the end of the incomplete statement.
#5expected ',' or ';'
CompilerThe compiler expected a comma or semicolon to continue or end a declaration or statement.FixAdd a semicolon (';') at the end of the incomplete statement.

#2expected '}' (before|after)
CompilerThe compiler expected a closing brace at this point.FixAdd the missing closing brace '}'.
#3unmatched '{'
CompilerAn opening brace '{' has no matching closing brace.FixAdd the missing closing brace '}'.

SYNTAX_ERROR15 rules
#1expected (primary-expression|unqualified-id)
CompilerThe compiler expected a valid expression but found unexpected text.FixFix the syntax error at the indicated location.
#2expected '(class|struct|typename)' keyword
CompilerA template parameter declaration requires the 'class' or 'typename' keyword.FixWrite 'template <typename T>' or 'template <class T>' for the template parameter.
#3'([^']+)' declared as a parameter
CompilerA function parameter name conflicts with a local declaration.FixUse distinct names for the parameter and the local variable.
#4'auto' type specifier requires an initializer
CompilerA variable declared with 'auto' must have an initializer so the type can be deduced.FixWrite 'auto x = <value>;' to allow the type to be deduced.
#5jump to (label|case) ... crosses initialization
CompilerA goto or switch statement jumps over a variable initialization.FixMove variable declarations before the jump point, or enclose the initialization in a block.
#6'...' is not (a struct|a class|a union|an enum|a namespace)
CompilerAn identifier is used as a type but is not one.FixDefine the struct, class, enum, or namespace with the expected name.
#7case value '...' not in enumerated type
CompilerA switch case value does not belong to the switch expression's enumerated type.FixReplace the case value with a valid enum member from the type used in the switch expression.
#8this declaration has no storage class or type specifier
CompilerA declaration at global scope is missing a type or storage class.FixMove the code inside a function, or add the required type to the declaration.
#9expected expression
CompilerThe compiler expected a valid expression at this point.FixProvide a valid expression at the indicated location.
#10stray '...' in program
CompilerA character that has no syntactic meaning in this context was found.FixRemove the stray character from the source file.
#11unexpected token
CompilerThe compiler encountered a token it did not expect at this position.FixRemove or relocate the unexpected token.
#12initializer list fallback disabled
CompilerInitializer list syntax is used in an unsupported context.FixUse parentheses () for constructor calls or explicit assignment for non-aggregate types.
#13lambda expression.*not allowed in this context
CompilerA lambda expression is used where lambdas are not permitted.FixExtract the lambda body into a named function or use it in an expression context.
#14expected (type-specifier|a type)
CompilerThe compiler expected a type name at this location.FixAdd the correct type name at the indicated location.
#15initializer for aggregate with no elements requires explicit braces
CompilerAn empty aggregate initializer requires explicit braces {}.FixUse '= {}' or '{}' to initialize the aggregate explicitly.
UNDEFINED_VARIABLE6 rules
#1'...' was not declared in this scope; did you mean '...'
CompilerThe identifier is not declared; the compiler suggests a similar name (GCC did-you-mean).FixUse the suggested name, or declare the intended identifier before using it.
#2was not declared in this scope
CompilerGCC: the identifier is not in any visible scope.FixDeclare the variable before using it, or fix the spelling if it is a typo.
#3use of undeclared identifier
CompilerClang: the identifier has no visible declaration.FixDeclare the identifier before using it, or add the required #include.
#4undeclared identifier
CompilerAn identifier used in this expression has not been declared.FixAdd a declaration for the identifier before it is used.
#5'...' (was not declared|is not declared)
CompilerThe named identifier has not been declared in this scope.FixDeclare the variable or add the required #include directive.
#6identifier '...' is undefined
CompilerThe identifier has no definition visible at this point.FixAdd the variable declaration or include the appropriate header.
UNDEFINED_TYPE2 rules
#1unknown type name
CompilerThe compiler does not recognise this as a known type.FixAdd the required #include or define/typedef the type before using it.
#2'...' does not name a type
CompilerThe identifier is not a known type in this context.FixAdd the type definition, include the required header, or fix the spelling.
UNDEFINED_FUNCTION2 rules
#1call to (undefined|undeclared) function
CompilerThe function called has not been declared.FixAdd a function declaration (prototype) before the call site, or include the header that declares the function.
#2implicit declaration of function
CompilerThe function is used without a prior declaration.FixDeclare the function before calling it, or include the appropriate header.
MISSING_INCLUDE8 rules
#1use of undeclared identifier 'std' [Clang — priority 15]
CompilerThe 'std' namespace is not visible because no standard-library headers have been included.FixAdd the required #include at the top of your file (e.g. #include <iostream>).
#2no member named '...' in namespace 'std'
CompilerThe std namespace does not contain this member — required header not included.FixAdd the appropriate #include for the standard library symbol you are using.
#3'...': file not found
CompilerThe compiler cannot find the included header file.FixCheck the filename spelling, add the missing include directory, or install the required library.
#4namespace '...' has no member named
CompilerThe accessed name does not exist in the namespace — possibly a missing include.FixAdd the required #include or correct the namespace qualifier.
#5is not a member of 'std' [GCC]
CompilerThe compiler does not recognise the identifier as a member of 'std' — required header missing.FixAdd the missing #include directive for the standard-library header that defines the symbol.
#6no include path in which to search for
CompilerThe compiler cannot find the specified header file in its include search paths.FixCheck the filename spelling, add the directory to the include path, or install the missing library.
#7no such file or directory
CompilerThe compiler cannot find the included file.FixCorrect the filename or install the missing library package.
#8size_type.*not a member of.*std
CompilerThe std::size_type is not visible because the required header is missing.FixAdd the appropriate #include for the container (e.g. #include <vector>).
TYPE_MISMATCH12 rules
#1cannot initialize a variable of type '...' with [Clang]
CompilerThe compiler cannot use the given value to initialize a variable of the declared type.FixChange the initializer to match the variable type, or cast the value explicitly.
#2cannot initialize return object of type [Clang]
CompilerThe return value type does not match the declared return type of the function.FixChange the returned value to match the function's return type, or update the return type declaration.
#3assigning to '...' from incompatible type [Clang]
CompilerThe value being assigned is not compatible with the variable's type.FixUse a value of the correct type or add an explicit cast.
#4no viable conversion from '...' to '...'
CompilerThe compiler found no way to convert between these two types.FixProvide an explicit conversion operator or constructor, or change the types to be compatible.
#5cannot convert [GCC]
CompilerThe compiler cannot implicitly convert the value to the required type.FixUse a value of the correct type, or add an explicit cast if the conversion is intentional.
#6invalid conversion from [GCC]
CompilerThe compiler detected an invalid implicit type conversion.FixUse a value of the correct type, or add an explicit cast if the conversion is intentional.
#7static_cast from '...' to '...' is not allowed
CompilerThe requested static_cast between these types is not permitted.FixUse the correct cast operator for the types involved, or redesign to avoid the cast.
#8return type '...' must match previous return type
CompilerConflicting return types in a function definition.FixMake the return type consistent between the declaration and definition.
#9narrowing conversion from '...' to '...'
CompilerA value is narrowed (truncated) when converting to a smaller type.FixUse an explicit cast to silence the error intentionally, or use a larger type.
#10incompatible types
CompilerThe types of the operands or assignment sides are incompatible.FixCast one operand to the correct type, or change the variable types to match.
#11implicit conversion (from|loses)
CompilerAn implicit type conversion may lose information.FixUse an explicit cast to make the conversion intentional, or use a type that fits the data.
#12comparison between (signed and unsigned|pointer and integer)
CompilerA comparison is made between incompatible integer types.FixCast one operand to match the other type, or use consistent signedness across comparisons.
CONST_VIOLATION1 rule
#1binding reference of type '...' to value of type '...' drops (const|volatile) qualifier
CompilerA reference is binding to a value but discarding a const or volatile qualifier.FixChange the reference to 'const T&' or use a const_cast if intentional.
WRONG_ARGUMENTS5 rules
#1requires \d+ arguments?, but \d+ (was|were) provided [Clang]
CompilerThe function requires a different number of arguments than were provided.FixAdjust the function call to provide the exact number of arguments the function expects.
#2no matching function for call to [GCC + Clang]
CompilerThe compiler could not find an overload that accepts the argument types or count provided.FixAdjust the call to match the function signature — correct number and types of arguments.
#3too few arguments to function [GCC]
CompilerThe function call provides fewer arguments than required.FixAdd the missing argument(s) to the function call to match the function signature.
#4too many arguments to function [GCC]
CompilerThe function call provides more arguments than the function accepts.FixRemove the extra argument(s) from the function call.
#5no viable overloaded '(operator...)'
CompilerNo overload of the operator matches the operand types.FixDefine the operator overload for the types used, or convert the operands to compatible types.
WRONG_CONSTRUCTOR2 rules
#1no matching constructor for initialization
CompilerNo constructor matches the argument types used in the initialization.FixUse an argument type that matches an existing constructor, or add a new constructor.
#2no matching (constructor|conversion function) for
CompilerNo constructor or conversion function matches the argument types.FixCorrect the constructor arguments or add a matching constructor overload.
WRONG_CALL1 rule
#1'...' is not a function
CompilerThe identifier is being called as a function but is not a function.FixEnsure the identifier refers to a callable function, not a variable or type.
MISSING_RETURN3 rules
#1non-void function '...' should return a value [Clang]
CompilerA function with a non-void return type does not return a value on some path.FixAdd 'return <value>;' before the closing brace of the function.
#2function does not return a value
CompilerA non-void function reaches the end without a return statement.FixAdd a return statement with an appropriate value to all exit paths of the function.
#3control (reaches|may reach) end of non-void function [GCC]
CompilerThe compiler detected that control can reach the end of a non-void function without returning.FixEnsure every execution path in the function returns a value of the declared type.
WRONG_RETURN1 rule
#1void function '...' should not return a value
CompilerA void function has a return statement that returns a value.FixChange 'return <value>;' to just 'return;', or change the return type of the function.
POINTER_ERROR6 rules
#1indirection requires pointer operand
CompilerThe dereference operator '*' is applied to a non-pointer value.FixRemove the '*' dereference operator, or change the variable to a pointer type.
#2cannot take the address of an rvalue
CompilerThe address-of operator '&' is applied to a temporary (rvalue), which has no address.FixAssign the value to a local variable before taking its address.
#3cannot dereference non-pointer type
CompilerA dereference operation is attempted on a non-pointer type.FixRemove the '*' operator or declare the variable as a pointer.
#4dereferencing pointer to incomplete type
CompilerA pointer is dereferenced, but the pointed-to type is only forward-declared.FixAdd the full class/struct definition with #include before the dereference point.
#5taking address of temporary
CompilerA pointer is taken to a temporary value, which will be destroyed after the statement.FixAssign the value to a local variable, then take its address.
#6(subscript|array subscript) of pointer to incomplete type
CompilerArray subscript is used on a pointer to an incomplete (forward-declared) type.FixAdd the full type definition with #include before the subscript operation.
REFERENCE_ERROR1 rule
#1cannot bind (non-const|rvalue reference of type)
CompilerA reference binding constraint is violated.FixChange the parameter or variable to 'const T&' or pass by value.
TEMPLATE_ERROR5 rules
#1template (instantiation|argument) (deduction (failed|error)|error)
CompilerThe compiler cannot deduce the template arguments from the provided arguments.FixProvide explicit template arguments like func<int>() or ensure argument types are correct.
#2invalid use of (incomplete type|template)
CompilerA template or incomplete type is used in a way that is not permitted.FixMove the full type definition before the template instantiation.
#3'typename' (keyword|specifier) used outside of template
CompilerThe 'typename' keyword is used where it is not applicable.FixRemove the 'typename' keyword, or move the code into a template context.
#4use of class template '...' requires template arguments
CompilerA class template is used without specifying its required type arguments.FixAdd the template type argument (e.g. change 'vector' to 'vector<int>').
#5in instantiation of (function|class|member) template
CompilerThe error occurred inside a template instantiation.FixEnsure the types used to instantiate the template satisfy all type requirements.
ITERATOR_ERROR1 rule
#1no (type|member) named 'iterator' in '...'
CompilerThe type used does not have an iterator member type.FixUse a standard container type or define the iterator type in your class.
OPERATOR_ERROR5 rules
#1(no match|no viable) for operator
CompilerNo matching operator overload is found for the given operand types.FixConvert the operands to compatible types or define the operator overload.
#2overloaded '...' not found
CompilerThe compiler could not find a matching overloaded operator.FixAdd an operator overload function that handles the types used.
#3invalid operands to binary expression
CompilerThe binary operator has operands of incompatible types.FixConvert the operands to compatible types or define the operator overload.
#4expression is not assignable
CompilerThe left-hand side of an assignment is not assignable (not an lvalue or is const).FixRemove the const qualifier from the variable, or change the code to avoid assigning to a non-assignable expression.
#5lvalue required as (left operand of|unary|assignment target)
CompilerAn assignable location (lvalue) is required but a temporary or literal was provided.FixAssign to a named variable instead of a literal or temporary expression.
ACCESS_VIOLATION2 rules
#1private member '...' of class '...'
CompilerA private member of the class is being accessed from outside the class.FixAccess private members only from within the class or through a public interface.
#2'...' is (a private|private|protected) member
CompilerThe member cannot be accessed from the current context due to access control.FixProvide a public accessor method or declare the accessing code as a friend.
ABSTRACT_CLASS3 rules
#1object of abstract class type '...' is not allowed
CompilerCannot instantiate an abstract class — it has unimplemented pure virtual functions.FixCreate a derived class that overrides all pure virtual methods, then instantiate that derived class.
#2(cannot|not allowed to) instantiate abstract class
CompilerA class with pure virtual functions cannot be instantiated directly.FixCreate a concrete derived class that implements all pure virtual methods.
#3call to (pure virtual|overridden) function
CompilerA pure virtual function is called directly, which is not allowed.FixOverride the pure virtual function in a concrete derived class and call through an instance of that class.
INCOMPLETE_TYPE2 rules
#1member access into incomplete type
CompilerA member is being accessed on a type that is only forward-declared, not fully defined.FixMove the #include for the full class definition before the point of member access.
#2forward declaration of '...'
CompilerOnly a forward declaration is visible here, not the full definition.FixAdd the full type definition or move the #include before this usage.
DELETED_FUNCTION1 rule
#1use of (deleted function|deleted member function)
CompilerA function that has been explicitly deleted (with '= delete') is called.FixAvoid calling the deleted function. If copying or moving is needed, implement the appropriate constructor/assignment operator.
REDEFINITION3 rules
#1redefinition of '...'
CompilerThe same name is defined more than once in the same scope.FixRemove the duplicate definition or rename one of the definitions.
#2conflicting (types|return type|declaration)
CompilerA name is declared or defined with conflicting types.FixMake the type consistent across all declarations and definitions.
#3previous definition is here
CompilerThis note indicates where the first definition appears.FixRemove the duplicate definition or rename one instance.
SHADOWING1 rule
#1declaration of '...' shadows a (parameter|local|global|member)
CompilerA new declaration hides a name from an outer scope.FixUse a unique name for the inner variable to avoid shadowing.
LINKER_ERROR3 rules

#2undefined (reference|symbol) to '...'
CompilerThe linker could not find the definition for the named function or variable.FixProvide the function definition, or link the required library with -l<libname>.
#3multiple definition of '...'
CompilerThe same function or variable is defined in multiple translation units.FixUse 'inline' for header-only definitions or move the definition to a single .cpp file.

CONSTEXPR_ERROR1 rule
